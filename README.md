# PEANUTS™ Reader

An unofficial, fan-made, non-commercial website for reading Peanuts comic strips by date.

- Open `peanuts-reader.html` in a browser, or host it on any static web host.
- Strips and fun-fact notes load from the [Peanuts Wiki](https://peanuts.fandom.com) in the reader's own browser. **This repository stores no comics and no logo or character artwork.**
- Optional: build `peanuts-index.json` with the in-page Statistics tool (turn on *Settings → Advanced → Show data notes and tools*, then *Build index file*) and put it next to the page for faster loading. It holds only file names, image addresses and the wiki's notes (CC BY-SA), not images.

## Logo and tab icon

They are not included in this repository. Without them the page shows a plain text title. For your own copy, save your images as `assets/logo.png` and `assets/favicon.png`. The `assets/` folder is git-ignored, so they are never published.
